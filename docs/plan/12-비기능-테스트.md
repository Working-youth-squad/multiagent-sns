# 12. 비기능 요구사항 · 예외/테스트 케이스

> 상위: [PLAN.md](../PLAN.md)

## 1. 비기능 요구사항 (NFR)

| ID | 요구사항 | 수용기준 |
|---|---|---|
| NFR-1 | **공식 API만 사용**(비공식 스크래핑/자동화 금지) — 계정 안전 | 의존성·코드에 비공식 클라이언트 0 |
| NFR-2 | **결정론 재현** = 테스트 타당성 전제. 주입식 모델·시계·transport, 시드 고정 | 가짜 모델 사이클 재현 CI 강제 |
| NFR-3 | **missing=NULL** DB CHECK 물리 강제 | CHECK 위반 삽입 거부 |
| NFR-4 | **멱등성**: 이중 발행 0, run_event append-only(best-effort) | 재시작 복구·이벤트 유실이 발행 성공 막지 않음 |
| NFR-5 | **자기 채널 성장만 측정**: 자기 베이스라인 대비 기울기. 타 계정과 절대 순위 비교 금지 | 비교 UI 부재, 한계 문구 상시 |
| NFR-6 | **정직 귀인**: 근거 없는 인과 주장 금지, 오버클레임 금지, n=1·초기 표본 한계 명시 (통계 구현체 = FR-A4) | 리포트 한계 절 |
| NFR-7 | **시크릿 암호화**: 토큰 앱레벨 암호화 후 DB 저장, 키=env/Secret Manager, 키 회전(key_version) | 평문 grep 0, 키 부재 시 기동 실패 |
| NFR-8 | **인프라 상한 = Docker Compose**(단일 호스트), CI/CD=GitHub Actions. k8s 등 과설계 금지 | compose로 전 서비스 구동 |
| NFR-9 | **마이그레이션** 전진 순번·트랜잭션 원자성 | 적용·버전 갭 테스트 |
| NFR-10 | **계정 안전 운영**: 워밍업 후 연동, 보수적 발행 빈도, 한도 존중 | 최초 발행 전 체크리스트 |
| NFR-11 | **[신설 v2] 콘텐츠 정책 안전**: 유튜브 "비진정성 콘텐츠" 정책(2025-07 — 템플릿 양산은 AI 여부와 무관하게 수익화 배제)·인스타 비독창 억제(어그리게이터=추천 표면 제외) 대응 — ① 매 콘텐츠 구조를 실질적으로 다르게(FR-A2 유사도 검사) ② 자체 제작 그래픽(코드 화면·도표) 매 콘텐츠 포함 ③ 타인 클립·밈 영상 미사용(저작권) | 유사도 검사 게이트 작동 + 발행물 전수 자체 그래픽 포함 |

## 2. 예외 · 엣지 · 테스트 케이스 (로직 체크)

| 요구사항 | 케이스 | 유형 | 기대 결과 |
|---|---|---|---|
| FR-P3 | 발행 중 크래시(pending/container_created/publish 3지점) | 예외 | 상태별 복구, 이중 발행 0 |
| FR-P4 | IG 토큰 만료(190류)/YouTube 401 | 예외 | 해당 채널만 중지+알림, 타 채널 발행 계속 |
| FR-P5 | YouTube 업로드 쿼터 소진 / IG 24h 발행 한도 초과 | 예외 | 잔여 발행 스킵·다음 창 대기+알림 |
| FR-P1/P2 | 컨테이너 생성 성공 후 게시 실패(transient) | 엣지 | RetryPolicy 지수 백오프, container 재사용 |
| FR-M2 | 영상 규격 위반(길이 초과·가로 영상) | 예외 | 렌더 단계 사전 검증 실패 → 발행 차단 |
| FR-M1/M2 | 같은 spec 두 번 렌더 | 설계 | 같은 checksum(결정론), 산출 재사용 |
| FR-L1 | 플랫폼이 지표 미노출(신규 게시물·비공개 지표) | 엣지 | metric_value=NULL, 0으로 안 채움 |
| NFR-3 | missing=true인데 value 동시 삽입 | 예외 | CHECK 위반 거부(스키마 차단) |
| FR-L2 | 관측 창 표본 부족 / reward 산식 미확정 | 예외 | reward=NULL, 학습에서 제외 |
| FR-L3 | topic_stats 빈 데이터(콜드 스타트) | 엣지 | 균등 탐색(sweep-first)으로 시작 |
| FR-L3 | 같은 시드·같은 통계 재실행 | 설계 | 같은 선택(결정론) |
| FR-L5 | 분석글이 실재하지 않는 post_id 인용 | 예외 | 출력 검증기 거부·재생성, 미통과 시 미게시 |
| FR-L5 | 인용 불가한 외부요인 추정 주장 | 정상 | insufficient_evidence=1, "근거 부족" 표기 |
| FR-L5 | 분석글 수치가 코드 집계와 불일치 | 예외 | 검증기 거부(수치는 코드만) |
| FR-C3/NFR-2 | 실모델로 재시작 시 본문 재생성 | 설계 | `content_item.body` 정본 유지(재생성 금지) |
| FR-C4 | LLM이 착지점 외 테이블 기록 시도 | 설계 | 툴 미노출로 불가 — 부재 단정 테스트 |
| NFR-7 | 암호화 키 env 부재 / 키 회전 | 예외·정상 | 기동 실패 / key_version 병존 후 재암호화 |
| FR-W2 | 운영 중 goal/도메인 변경 | 정상 | 새 국면(기저 재수집), 옛 데이터 불변 |
| FR-P5 | 동일 슬롯 다채널 발행 폭주 | 동시성 | 러너 큐 직렬화, 한도 내 분산 |
| FR-E1 **[v2]** | hybrid 채널에서 미승인 초안 발행 시도 | 예외 | needs_review 관문에서 차단 |
| FR-E3 **[v2]** | hybrid에서 사람이 초안 수정 후 승인 | 정상 | edited_by_human=true 기록 |
| FR-A2 **[v2]** | 직전 N건과 구조 유사도 초과 콘텐츠 | 예외 | 발행 차단 + 사유 기록 |
| FR-A4 **[v2]** | 게시물 30건 미만에서 회귀 분석 요청 | 설계 | 회귀 미표시, 상관+신뢰구간만 |
| FR-A5 **[v2]** | 계정 4개 동시 지표 급변 주입 | 설계 | "알고리즘 변화" 판정, 분석글 반영 |
| FR-W4 **[v2]** | 발행 실패 시 LLM 원인 분석 호출도 실패 | 예외 | 분류명만으로 알림 발송(알림 유실 0) |

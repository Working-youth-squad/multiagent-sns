# 09. 알고리즘 신호 최적화 (FR-A)

> 상위: [PLAN.md](../PLAN.md) · **[신설 v2]** · 근거: 3갈래 딥리서치(IG 공식 신호·YT 쇼츠 공식 신호·추천시스템 구조/실증 연구, 2026-08)

## 1. 설계 원칙 — 규칙이 아니라 신호를 최적화한다

1. **공식 랭킹 신호는 소수이고 전부 API로 측정 가능** — IG(Mosseri·공식 랭킹 문서): watch time · likes/reach · **sends/reach**(비팔로워 추천에서 최중요), 감점 요인(타 플랫폼 워터마크·저해상도·텍스트 과다·무편집 재게시) / YT(Creator Insider 공식): **viewed vs swiped away**(노출 시 시청 선택률 — API 근사 = `engagedViews/views`) · 평균 시청 시간/비율 · 만족도(좋아요+설문). 유튜브는 길이 보너스·발행 시간 효과·구독자 수 랭킹 반영을 **공식 부인**.
2. **신규 콘텐츠는 시드 오디언스 테스트 → 단계 확산** (양사 공식 확인 — IG는 Trial Reels로 제품화, YT는 Sherman 공식 설명). 게시 후 초기 신호가 확산을 결정.
3. **알고리즘 "규칙" 역공학은 유효기간이 짧다**(감사 재현성 연구) + **결과 분산은 구조적**(같은 품질도 조회수 10배 차이 — Music Lab·숏폼 분산 연구). → 규칙 하드코딩이 아니라 **공식 신호 측정 + 자기 계정 기준선 대비 지속 재추정**으로 설계하고, 소표본 과잉 해석을 막는다.

## 2. 요구사항 (FR-A)

| ID | 요구사항 | 수용기준 |
|---|---|---|
| FR-A1 | **신호 스코어보드**: 게시물별 공식 신호 계산 — IG: `shares/reach`·`likes/reach`·`saved/reach`·완주 근사(`ig_reels_avg_watch_time`÷길이), YT: `engagedViews/views`·`averageViewPercentage` — **계정 자체 기준선(중앙값) 대비** 상·하위 태깅, 상위 콘텐츠 공통 요소(hook_pattern·주제·길이) 리포트 → 인사이트 탭([10](10-웹-알림.md) FR-W3) | 신호값·기준선·태깅이 코드 집계로 조회 가능 |
| FR-A2 | **발행 전 감점 요인 검사**(FR-Q1 확장): 해상도<1080×1920, 음소거, 텍스트 안전영역(중앙 900×1400 박스, [06](06-미디어렌더.md) §4) 위반, **직전 N건과 구조 유사도**(비진정성/어그리게이터 판정 방어 — NFR-11) | 위반 자산 발행 차단, 사유 기록 |
| FR-A3 | **초기 확산 조기 판정**: FR-L1의 6·24·72h 곡선으로 계정별 "첫 N시간→최종 성과" 상관 축적 → 확산/소멸 조기 분류, 소멸 판정 시 알림(FR-W4)+개선 제안 | 표본 축적 전에는 "판정 불가" 표기 |
| FR-A4 | **소표본 정직 통계**(NFR-6의 통계 구현): 분석은 log(조회수)·계정 내 백분위만 사용, 게시물 30건 미만이면 회귀 금지(상관+신뢰구간만), 리포트에 "동일 품질도 조회수 10배 차이 가능(분산 연구 근거)" 상시 표기 | 30건 미만 데이터에 회귀 결과 미표시 |
| FR-A5 | **알고리즘 변화 감지**: 계정별 도달/조회 시계열에 체인지포인트 탐지 — **계정 4개 중 다수에서 동시 변화 = 알고리즘 변화로 판정**(내 콘텐츠 문제와 구분, 잘못된 귀인 방지) → 분석글에 반영 | 동시 변화 시나리오 주입 테스트 |

## 3. 구현 범위 배치

- **2주차**: FR-A2(렌더 게이트 통합 — 근거가 가장 단단), FR-A1 수집부.
- **3주차**: FR-A1 리포트·FR-A3 알림·FR-A4(분석글 규칙).
- **후속**: FR-A5(표본 축적 필요, 3주차 말 시범).

## 4. 통설로 분류된 것 (서비스 문구에서 "공식" 표기 금지)

sends 가중치 배수 · 확산 시간표(첫 1시간 등) · 최적 길이 30~90초 · 해시태그/발행 요일의 직접 랭킹 반영. 발행 시간 최적화는 근거 약(유튜브 공식 부인) — 현 설계의 발행 슬롯·지터는 스팸 방지 목적으로만.

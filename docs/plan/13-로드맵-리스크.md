**담당 배정 원칙(DRI).** 모듈마다 단일 책임자 1명을 착수 전에 확정(리뷰어 별도). 미배정 모듈은 착수하지 않는다. seam 계약 변경 권한은 그 seam의 DRI에게만. 난이도 '상'(M2·M4·M5·M6)은 주담당+백업 2인 권장. **[v2] 2인 팀이므로**: 역할 A(시스템 — M1·M5·M8), 역할 B(콘텐츠·학습 — M3·M4·M6·M7), M2는 공동 착수 후 주담당 확정을 제안.

**병렬화 전략(seam-first)**: 먼저 M1(DB 스키마 + 툴 계약 타입)을 확정해 seam을 고정하면, M3~M6을 가짜(fake) 어댑터/모델로 병렬 개발할 수 있다.

## 2. 로드맵

### Phase 구조 (원안 유지)

- **Phase 0 — seam 확정 + 전제 스파이크(게이트)**: M1 스키마 + 툴 타입 계약 + 결정론 하네스. 세 스파이크를 착수 게이트로 선행:
  - **① deepagents 계약 적합성**: (a) 모델·시계·transport 주입식 대체 (b) 가짜 모델로 한 사이클 결정론 재현 (c) LLM 기록 착지점 3곳 통제 — 최소 예제로 검증. **게이트**: 하나라도 막히면 deepagents 코어를 버리고 **자작 오케스트레이터로 폴백**(툴 계약·착지점·하네스는 유지).
  - **② 콘텐츠 품질 하한(정량 게이트)**: **[개정 v2] 포맷별 5~8건**(원안 20건, 일정 압축 — 리뷰어 2인 독립 판정 유지), 전항목-pass ≥60%(초안)면 통과. **TTS 엔진·렌더러·디자인 시스템도 함께 확정**([06](06-미디어렌더.md) 결정 자료).
  - **③ 경량 수요 벤치마크**: 유사 개발자 채널의 공개 지표만 소수 수집 → S1 목표치 사전등록의 사전분포 근거(비공식 스크래핑 금지).
- **Phase 1 — 실환경 관통**: 발행→지표→reward→리포트 관통. 품질 게이트(FR-Q) 필수, 비용 하드 상한(FR-P6) 적용.
- **Phase 2 — 자율 루프**: 스케줄러 상주 + 학습 + 플레이북 + 분석글. cost cap 승격.
- **Phase 3 — 운영 성숙**(상시) / **Phase 4 — 후속**(채널 확장·다중 계정, 선결: 성장 기울기 검증).

### 확정 일정 [개정 v2]: 총 2~3주

단기 조항 발동 — DoD는 엔지니어링 관통까지([PLAN.md](../PLAN.md) §4.1), S1 판정은 종료 후 관측 지속, kill criteria K2~K4만 활성.

| 주차 | 내용 |
|---|---|
| **1주차** | Phase 0 압축 병렬: 스파이크 ①(2~3일)·②(5~8건)·③(반나절). 병행: **1일차 Meta 앱 권한 신청(최장 리드타임)** · 계정 4개 개설+프로필+워밍업 시작 · M1 스키마+툴 계약 확정 → 병렬 개발 개시 |
| **2주차** | Phase 1 관통: 계정 4개 전부 IG 피드·릴스 + YT 쇼츠 자동 발행 → 지표 → reward → 리포트 1회 관통 + Discord 알림(FR-W4) + 감점 검사(FR-A2) |
| **3주차** | Phase 2 착수: 스케줄 상주 + 플레이북 루프 + 인사이트 탭(FR-W3) + **auto vs hybrid 비교 리포트(FR-E4) — 최종 산출: 인사이트 보고** |

> **핵심 제약(원칙 유지):** S1(성장 기울기)은 발행→반응 누적이라는 캘린더 시간을 요구하므로 이 일정 안에서 성장 판정은 물리적으로 불가하다. 이번 라운드의 성공 기준은 엔지니어링 관통 + auto/hybrid 비교의 **초기 신호**까지다.

## 5. 외부 제약 (구현 전 최신값 재확인)

- **Instagram Graph API**: 프로페셔널 계정 + 연결된 Facebook 페이지 필요. 게시 2단계(컨테이너→게시). 계정당 24시간 발행 한도(과거 25건 기준). 릴스는 동영상 컨테이너.
- **YouTube Data API v3**: `videos.insert` 쿼터 비용 큼(1회 ~1600 units, 일 10,000 units → 하루 수 건). 쇼츠는 세로 영상 + #Shorts.
- **Meta/Google 심사**: 타인 계정 대상 확장 시 App Review 게이트 — 이번 범위 밖.
- **[최신화 v2]** 릴스 최대 3분(2025-01, 3분 초과분 신규 추천 제외 관찰) · 쇼츠 최대 3분(2024-10) · **YT 조회수 집계 변경(2025-03)**: `views`=재생 시작, `engagedViews`=의미 있는 시청(수익화 기준) · 인스타 어그리게이터 억제(2024-04~): 30일 내 무편집 재게시 10회↑ 추천 제외 · IG 인사이트 메트릭 개편(v22: plays·impressions deprecated → views).
- 수치는 정책 변동이 잦으므로 **구현 착수 시 공식 문서로 재확인**한다.

# 07. 웹 화면

> 담당 역할: **역할 B (콘텐츠·에이전트)** · 관련 요구사항: 12, 13, 14 · 상위 문서: [기획서 총괄](../기획서.md)
> 스택: React+Vite (feedr-clone 화면 구조·인증·API 래퍼 이식). **자동화 기능만** — 마케팅/랜딩/꾸미기는 배포일 확정 후 (요구사항 14)

## 1. 채널 연결

- OAuth로 IG/YT 계정 연결 (oauth-start → 플랫폼 동의 → oauth-callback → 토큰 암호화 저장)
- 토큰 상태 표시: 정상 / 만료 임박 / 만료(`expired`) / 차단(`blocked`) + 재연동 버튼

## 2. 오토파일럿 설정

- 채널별: 모드(auto / hybrid / off), 페르소나, 콘텐츠 지침(자유텍스트), 일 발행 한도, 슬롯 시각
- "지금 실행" 버튼 — GitHub API `workflow_dispatch` 호출로 agent-cycle 즉시 실행
- 실행 기록(autopilot_runs) 목록: 보고서 + 액션 내역 펼쳐보기 (feedr-clone 계승)

## 3. 대기열 (hybrid 모드의 사람 개입 지점)

섹션 4개 (feedr-clone 계승):

| 섹션 | 기능 |
|---|---|
| 승인 대기 | **주제 제안 3~5개 중 선택**(topic_suggestions), 초안 인라인 편집(제목/대본/발행시각), 영상 미리보기, **승인/반려** |
| 예약됨 | 발행 예정 목록, 시각 수정, 취소 |
| 발행 완료 | external_id 링크(실제 게시물로 이동) |
| 실패 | 오류 분류·메시지 노출, 재시도 버튼 |

사람이 수정하면 `posts.edited_by_human=true` 기록 → 인사이트 분석 축.

## 4. 인사이트 탭 (요구사항 12·13 — 데이터 정의는 [06-지표·인사이트](06-지표-인사이트.md) §3)

| 구역 | 내용 | 시각화 |
|---|---|---|
| ① 계정 카드 ×4 | 팔로워 추이, 일별 조회 | SVG 스파크라인(이식, 호버 툴팁) + 막대 |
| ② auto vs hybrid 비교 | 글당 조회·좋아요·참여율·팔로워 증가 4지표, 플랫폼별 | 비교 박스 (feedr-clone 계승) |
| ③ 성장 요약 | 성장 기울기, 발행 성공률, 사이클당 비용 | 수치 카드 |
| ④ 패턴 분석 | 훅 패턴별·발행 시간대별 성과 | 표 + 막대 |
| ⑤ 주간 분석글 | insight_reports — "크는/안 크는 이유", 수치 근거 인용 | 텍스트 (인용 수치 하이라이트) |

## 5. 알림 로그

- notifications 목록 (Discord와 이중화), 심각도(info/warn/error) 필터, 읽음 처리
- 항목 클릭 시 관련 게시물/채널로 이동

# 04. 트렌드 조사 (무료 외부 소스)

> 상위: [PLAN.md](../PLAN.md) · **[신설 v2]** — Topic Agent의 입력이 내부 `topic_stats`뿐이면 콜드 스타트 시 주제 발굴 경로가 없다.

## 1. 요구사항 (FR-G4)

| ID | 요구사항 | 수용기준 |
|---|---|---|
| FR-G4 | Topic Agent는 `research_trends` 툴로 **무료 외부 트렌드 소스**를 조회해 주제 발굴에 사용. 소스 일부 실패 시 조용히 제외하고 계속. **리서치로 확인 안 된 내용은 소재로 쓰지 않음**(프롬프트 규칙, 할루시네이션 방지) | 콜드 스타트 사이클에서 외부 소스 기반 topic 생성, 소스 1개 강제 실패 시에도 사이클 완주 |

## 2. 소스 구성 (전부 무료)

| # | 소스 | 방식 | 비용/한도 |
|---|---|---|---|
| 1 | Google Trends 한국 급상승 | RSS 파싱 | 무료, 무인증 |
| 2 | 네이버 검색 API (블로그/뉴스) | 공식 API | 무료 25,000회/일 |
| 3 | 네이버 데이터랩 | 검색량 30일 추이 → 상승/유지/하락 판정 | 무료 1,000회/일 |
| 4 | YouTube 인기영상 | `chart=mostPopular&regionCode=KR` | 1unit/회 (일 10,000) |
| 5 | GitHub 트렌딩 / GeekNews RSS | 개발 니치 특화 | 무료 |
| 6 | LLM 웹 그라운딩 (선택) | Gemini `google_search` | 무료 티어 내 |

**구현 원칙**: 소스별 타임아웃(10초) + 실패 시 null 반환 후 계속 — 하나 죽어도 리서치는 계속된다. 결과는 마크다운 다이제스트로 합쳐 Topic Agent 프롬프트에 주입.

## 3. 산출

- 다이제스트 → Topic Agent가 `topic_stats`(과거 성과)·`playbook`(학습된 지침)과 겹쳐 주제 선정.
- hybrid 채널([01](01-실험설계.md) FR-E1)은 주제 3~5개를 제안 상태로 저장 → 사람 선택 대기.

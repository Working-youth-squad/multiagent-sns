# 14. 작업 태스크 분할 (역할 배정 전)

> 상위: [PLAN.md](../PLAN.md) · [13-로드맵-리스크](13-로드맵-리스크.md)의 모듈 M1~M8을 실제 작업 단위로 세분화한 문서.
> **전제**: 2인 팀 · 충돌 최소화 병렬 작업 · 계정 관리는 인스타 1인·유튜브 1인(전체 내용은 상호 공유) · **담당자 이름은 이 문서에 없음 — 배정은 팀 협의로**.

## 0. 분할 원칙 (충돌 방지 규칙 5)

1. **seam 먼저, 함께**: DB 스키마·툴 계약은 T0에서 공동 확정 후 **동결**. 이후 변경은 반드시 PR + 상대 리뷰.
2. **태스크 = 디렉토리 1개**: 각 태스크는 소유 디렉토리가 겹치지 않는다. 같은 디렉토리를 두 사람이 동시에 작업하지 않는다.
3. **IG/YT 트랙은 Provider 계약 뒤에서 완전 독립**: 상대 트랙이 없어도 가짜(fake) 어댑터로 개발·테스트 가능.
4. **공통 태스크는 절반씩 소유**: 배정 시 예시 세트 — {C2, C4, C8, C10} / {C1, C3, C5, C6, C7, C9, C11} (규모 균형 맞춤, 조정 가능).
5. **main 직접 푸시 금지**: 짧은 PR을 자주. 리뷰는 상대 1인.

## 6. 역할 배정을 위한 준비 상태

이 문서는 배정만 하면 되는 상태다: **"트랙 IG + 공통 세트 α" / "트랙 YT + 공통 세트 β"**가 자연스러운 분배이며(α·β는 §0-4 예시 세트 참고), T0는 공동. 이름 기입은 팀 협의 후 [13-로드맵-리스크](13-로드맵-리스크.md) §1 DRI 표와 함께 갱신한다.

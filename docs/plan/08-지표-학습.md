# 08. 반응 학습 (지표 · reward · 밴딧 · 플레이북)

> 상위: [PLAN.md](../PLAN.md) · 시퀀스: [diagrams/learning-loop-sequence.mermaid](../diagrams/learning-loop-sequence.mermaid)

## 1. 요구사항 (FR-L)

| ID | 요구사항 | 수용기준 |
|---|---|---|
| FR-L1 | Analyst Agent가 발행 후 복수 시점에 인사이트 폴링 → `metric_observation`+`metric_value`. **결측=NULL**(0 금지). **[구체화 v2]** 폴링 시점 = 발행 후 **6h·24h·72h**(+이후 일 1회) — 시드 테스트→단계 확산이라는 플랫폼 공식 구조상 초기 곡선이 조기 판정 신호(FR-A3) | 미노출 지표가 NULL로 저장, CHECK 강제 |
| FR-L2 | `RewardFn(관측창)→float\|None`. goal별 산식, 데이터 부족/미확정=NULL(학습 제외). **[방향 확정 v2]** 산식은 **플랫폼 공식 신호와 같은 방향으로 정렬** — 완주 근사(avg_watch_time÷길이)·공유율(shares/reach)·YT `engagedViews/views` 중심 가중합, 조회수는 log 변환 보조(heavy-tail 방어). 계수는 M1 실측 후 사전등록 | reward NULL 행은 밴딧 집계에서 제외 |
| FR-L3 | `topic_stats`(주제×포맷×채널) 집계 → Growth Agent가 다음 사이클 변형 선택. **선택은 루프 밖 결정론(시드 고정)**. **[활성 조건 명시 v2]** 밴딧은 arm당 유효표본 ≥10 필요 — 계정당 일 1건×3주(≈20건)로는 통계 불성립. **이번 라운드는 균등 탐색+플레이북만 사용**, 밴딧은 arm≤5(`hook_pattern` 5종)로 축소해 **발행 50건 축적 후 활성**(K2 폴백의 선제 적용) | 같은 시드·같은 통계→같은 선택 |
| FR-L4 | `playbook` 갱신(성과 요약·지침) → 다음 사이클 콘텐츠 생성에 참조 | 플레이북 버전 증가, 콘텐츠에 반영 |
| FR-L5 | **LLM 분석글(정직 귀인)**: 입력=DB 근거. 인과 주장은 근거 인용 가능할 때만, 불가하면 **"근거 부족" 명시**. 수치는 코드 계산, LLM은 서술만. 출력 검증기가 인용 없는 단정·실재하지 않는 post_id를 거부 | 검증기 거부 테스트, 지어낸 인용 0 |

## 2. 학습 방식의 역할 분담 — 밴딧 vs 플레이북 [해설 v2]

| | 밴딧 (숫자 학습) | 플레이북 (언어 학습) |
|---|---|---|
| 배우는 것 | 조합 선택 (무엇을) | 제작 방식 (어떻게) |
| 필요 표본 | 많음 (arm당 ≥10) | 적음 (수 건) |
| 엄밀성 | 높음 | 낮음 → 정직 귀인 규칙으로 보완 |

둘은 상호보완이다. 이번 라운드는 표본 제약상 **플레이북이 메인**, `hook_pattern`별 성과 표(FR-A1)가 밴딧의 씨앗 — 표본이 쌓이면 그 데이터 그대로 밴딧으로 승격한다.

## 3. 밴딧 학습 입력 (`topic_stats`)

- 행동 공간 = **주제(topic) × 포맷(feed_image/reels/shorts) × 채널(instagram/youtube)** (활성 시 초기 arm은 hook_pattern 5종으로 축소 — FR-L3).
- `trials`, `reward_sum`으로 평균 보상 파생(NULL 보상 제외).
- Growth Agent가 이 통계를 읽어 다음 사이클 변형 선택(루프 밖 결정론 — 시드 고정). 콜드 스타트는 균등 탐색(sweep-first).

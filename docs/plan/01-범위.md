# 01. 범위

> 상위: [PLAN.md](../PLAN.md) · 관련: [08-지표-학습](08-지표-학습.md), [10-웹-알림](10-웹-알림.md)

## 1. 채널 구성

| 계정 | 플랫폼 | 포맷 |
|---|---|---|
| IG-A, IG-B | Instagram | 피드(카드뉴스 이미지) · 릴스 |
| YT-A, YT-B | YouTube | 쇼츠 |

전 채널이 **완전자동**으로 동작한다 — 기획→제작→검수→발행 전 과정 무인. 사람 승인 관문도, 채널별 운영 모드 분기도 두지 않는다. 채널 발행 중지는 `channel.status(active/paused/revoked)` 하나로 표현한다([11-데이터모델](11-데이터모델.md)).

**공통 설정** — 동일 주제 도메인·발행 슬롯·템플릿 풀·발행 빈도(일 1건)를 전 채널에 적용한다. 주제는 사이클당 1건이라 같은 사이클의 채널들은 같은 주제를 공유한다.

## 2. 범위

**포함(이번 라운드)**
- 채널: IG 피드(카드뉴스 이미지) · IG 릴스(영상) · YouTube 쇼츠(영상) — **전부 공식 API**.
- 주제 발굴 입력: **무료 외부 트렌드 소스** ([04-트렌드조사](04-트렌드조사.md)) — 내부 `topic_stats`만으로는 콜드 스타트 시 주제 발굴 경로가 없다.
- 영상: **템플릿 코드 합성**(자막+슬라이드+TTS). 렌더러는 Phase 0 품질 스파이크에서 확정 ([06-미디어렌더](06-미디어렌더.md)). 생성형 비디오 모델 미사용.
- 코어: **deepagents 프레임워크 그대로 도입** ([03-멀티에이전트](03-멀티에이전트.md)).
- 학습: 플레이북 갱신 + LLM 분석글(정직 귀인) + 알고리즘 공식 신호 스코어보드([09](09-알고리즘-신호-최적화.md)). 밴딧은 표본 축적 후 활성([08](08-지표-학습.md) FR-L3).
- 운영: 스케줄 실행(인프라는 [02](02-아키텍처-스택.md)·1주차 확정) + PostgreSQL + Docker Compose + GitHub Actions CI. 웹은 **알림·인사이트 탭 필수**([10](10-웹-알림.md)), 나머지 선택.
- 대상: **팀 소유 실험 계정 4개** (타인 계정 대행 없음).

**미포함(후속)**
- **사람 개입 운영 일체** — 수동(사람이 직접 작성·발행 후 등록)·반자동(AI 초안 → 사람 승인) 운영 모드, 승인 화면, 수동 프롬프트 시드 발행. 발행 경로는 하나다: AI 생성 → 품질 게이트 → 기계 발행.
- 다중 사용자 SaaS(다중테넌트)·타인 계정 대행 → Meta/Google App Review 게이트 발생, 이번 범위 밖.
- TikTok 등 추가 채널, 생성형 비디오, 실시간 라이브.

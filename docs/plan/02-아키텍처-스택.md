# 02. 시스템 아키텍처 · 기술 스택

> 상위: [PLAN.md](../PLAN.md) · 다이어그램: [diagrams/architecture.mermaid](../diagrams/architecture.mermaid)

## 1. 시스템 아키텍처

```
슬롯 스케줄러(러너)
      │ 사이클 트리거
      ▼
Orchestrator (deepagents main)
  ├─ Topic Agent     주제 발굴(트렌드·플레이북 참조)
  ├─ Content Agent   대본/카피/카드 문안 (LLM)
  ├─ Media Agent     이미지 카드 / 영상 템플릿 합성 (결정론 렌더)
  ├─ Publisher Agent IG Graph API · YouTube Data API (멱등 발행)
  ├─ Analyst Agent   지표 폴링 → reward → 분석글(정직 귀인)
  └─ Growth Agent    다음 사이클 변형 선택 (결정론)
      │
      ▼
PostgreSQL (단일 DB) ── 웹(알림·인사이트 탭 필수, 나머지 선택)
```

**제어 채널 분리**: 통제=코드(상태·수치·스케줄) · 판단=LLM(주제/글/분석 서술) · 경계=툴 타입 계약 + DB 착지점(3곳, [11-데이터모델](11-데이터모델.md) §6). LLM은 열거된 곳에만 기록하고 수치는 코드가 계산한다.

## 2. 기술 스택

| 층 | 선택 | 비고 |
|---|---|---|
| 언어 | Python 3.12 | |
| 에이전트 | **deepagents** (LangGraph 기반) | 코어 그대로 도입 ([03](03-멀티에이전트.md)) |
| LLM | **[개정 v2] 저비용 혼합**: 판단(주제 선정·대본·분석글)=Claude(`claude-sonnet-5`) · 대량 작업(트렌드 요약·자막 분절·해시태그)=Gemini Flash free tier(일 1,500회 무료) | 주입식(테스트 시 가짜 모델) · deepagents는 모델 주입 자유 · 비용 상한 FR-P6 유지 |
| DB | **PostgreSQL** | 단일 인스턴스, 정규화+CHECK |
| 이미지 | Pillow | 결정론 카드 렌더 |
| 영상 | **[개정 v2] ffmpeg+ASS vs Remotion — Phase 0 스파이크 확정**(moviepy 제외) | TTS 권장: Google Cloud TTS Chirp 3 HD ([06](06-미디어렌더.md)) |
| 발행 | Instagram Graph API · YouTube Data API v3 | 공식 API만 |
| 스케줄 | **[개정 v2]** 상주 러너(무료 VM) **또는** GitHub Actions cron — **1주차 확정** | 웹이 꺼져 있어도 실행이 요건. GHA는 무료·서버리스, 상주 러너는 정밀도 우위 |
| 인프라 | **Docker Compose** | k8s 미사용 |
| CI/CD | **GitHub Actions** | pytest+lint+타입 |
| 웹 | FastAPI + 경량 프론트 | 알림·인사이트 탭 필수([10](10-웹-알림.md)), 나머지 선택 |

> 스택 세부(TTS 엔진, ORM, 웹 프레임워크)의 결정 자료·확정 시점은 [13-로드맵·리스크](13-로드맵-리스크.md) §4 미결정 참조.
